# SANOTA Global — Exhibition QR Display & Product Showcase

An ultra-premium, light-theme corporate web application designed for **SANOTA Global** (https://www.sanotaglobal.com/) exhibition booths, conference displays, and mobile visitor interaction.

## Key Features

- **Single-Screen Conference Display (Zero-Scroll)**:
  - Engineered for 100vh kiosk and booth TV displays without vertical scrollbars.
  - Three-column executive layout: Grand typography, center high-contrast QR terminal card, and structured capability cards (01, 02, 03).
  
- **Direct High-Resolution QR Engine**:
  - Center QR terminal featuring the SANOTA brand badge and Level H error correction (scannable up to 5 meters).
  - One-click **Save QR** feature generating 1200px lossless raster PNG assets with embedded logo for marketing materials.

- **Product Showcase Video Gallery**:
  - 6 core solution categories: Industrial Machinery & Automation, Food & Tea Processing, Smart Agriculture Systems, IoT & Digital Platforms, Material Handling & Intralogistics, and Machine Retrofit & Upgrades.
  - Interactive cinema modal with telemetry HUD, waveform visualizer, and custom video URL injection.

- **Integrated Contact & Enquiry Suite**:
  - Live contact links: Website, Email, Phone, and Sri Lanka location.
  - Direct *"Have an engineering challenge? Start Your Enquiry"* callout.
  - Official social links for LinkedIn, Instagram, and Facebook.

## Tech Stack

- **Frontend**: React 19 + Vite 8
- **Styling**: Vanilla CSS (SANOTA Corporate Design Tokens: Deep Navy `#17135B`, Brushed Gold `#D4AF37`, Warm Cream `#FAF8F5`)
- **Icons**: Lucide React & Handcrafted Vector SVGs
- **QR Engine**: `qrcode` (Vector canvas & data URL rendering)

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build
```
